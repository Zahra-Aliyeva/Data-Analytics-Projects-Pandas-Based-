# Data Analytics Projects (Pandas-Based)
This repository contains multiple data analysis projects developed using Python and Pandas in Google Colab.
Each notebook focuses on data cleaning, exploration, visualization, and extracting insights from real-world datasets.

## Tools & Technologies
Python

Pandas

NumPy

Matplotlib / Seaborn

Google Colab

## Projects Included
### 1. Heart Disease Analysis, [here](https://github.com/Zahra-Aliyeva/Data-Analytics-Projects-Pandas-Based-/blob/main/Heart_disease.ipynb)

Exploratory data analysis of heart disease dataset.
Performed data cleaning, feature analysis, and identified key factors related to heart disease risk.

### 2. Students Performance Analysis, [here](https://github.com/Zahra-Aliyeva/Data-Analytics-Projects-Pandas-Based-/blob/main/Students_performance.ipynb)

Analyzed student performance data to explore relationships between study habits, demographics, and exam scores.

### 3. Superstore Sales Analysis, [here](https://github.com/Zahra-Aliyeva/Data-Analytics-Projects-Pandas-Based-/blob/main/Superstore.ipynb)

Sales data analysis including revenue trends, profit distribution, and product/category performance.

### 4. Zara Dataset Analysis, [here](https://github.com/Zahra-Aliyeva/Data-Analytics-Projects-Pandas-Based-/blob/main/Zara.ipynb)

Retail data exploration focusing on pricing patterns, product categories, and sales insights.

### 5. Car Data Analysis, [here](https://github.com/Zahra-Aliyeva/Data-Analytics-Projects-Pandas-Based-/blob/main/car_data.ipynb)

Analyzed car dataset to examine relationships between price, fuel type, engine specifications, and other attributes.

### 6. Player Role Clustering, [here](https://github.com/Zahra-Aliyeva/Data-Analytics-Projects-Pandas-Based-/blob/main/player_role_cluster.ipynb)

Applied clustering techniques to group players based on performance statistics.

## Key Skills Demonstrated
Data cleaning and preprocessing

Handling missing values

Exploratory Data Analysis (EDA)

Data visualization

Basic clustering techniques

Insight generation from raw datasets

## Goal of This Repository

The purpose of these projects is to strengthen practical data analysis skills and build a portfolio demonstrating hands-on experience with real datasets.
